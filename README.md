## 🎵 Dynamic Web Audio Evolution Synthesizer
- Built with the native Web Audio API (zero external audio file dependencies, 100% instant offline load).
- Continuous, seamless note-to-note transition across 4 distinct evolutionary instrument timbres:
  1. **Stage 0**: 8-Bit Chiptune 👾
  2. **Stage 1**: Crystalline Music Box ✨
  3. **Stage 2**: Warm Celesta 🎶
  4. **Stage 3**: Concert Grand Piano 🎹

## 📱 Mobile-First Features & UX
- **Zero-Latency Touch**: High-performance pointer events controller with automatic tap vs drag detection.
- **Swipe-Up Gesture Support**: Swipe up in Stage 0 to smoothly unwrap the gift.
- **Accessible Text & Viewport**: Retina-optimized display scaling, dynamic viewport height (`100dvh`), and safe-area inset adaptation for iPhone Dynamic Island and modern Android displays.
- **100% Standalone & Portable**: Single self-contained HTML file with embedded CSS, base64 photo asset, audio synthesis, and canvas physics engine.
